# 已归档的重型视觉路径

此目录保留过去的 Mage-VL 视频桥、LocateAnything 图像融合桥及其构建文件，作为迁移和安全审计的历史材料；它不是当前部署入口。

- `deploy/openclaw/docker-compose.yml` 不再引用这些文件。
- 当前 Compose 不构建、不启动视频桥或图像融合服务，`openclaw.json` 也不包含它们的模型路由。
- CI 不安装此目录的 Python 依赖，也不执行 GPU 模型。
- 重新启用前必须重新核对模型许可、镜像摘要、依赖锁定、GPU 预算和真实媒体行为；不能把本目录代码复制回默认启动链路。

代码仍可从 Git 历史恢复，因此没有在本轮删除；归档本身不构成已部署或可用的视觉服务证据。
